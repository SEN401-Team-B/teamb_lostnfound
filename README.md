# Team B – Lost & Found
![CI](https://github.com/SEN401-Team-B/teamb_lostnfound/actions/workflows/ci.yml/badge.svg)

A campus Lost & Found web app built for SEN401 (Software Configuration Management & Maintenance).
Students can report lost and found items, browse them and search for them.

## Run
```bash
npm install
npm start   # http://localhost:3000
npm test
```
